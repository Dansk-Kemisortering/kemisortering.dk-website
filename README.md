# kemisortering.dk

Marketing site for Dansk Kemisortering A/S — a single-page static site at
[www.kemisortering.dk](https://www.kemisortering.dk/).

Built with [Zola](https://www.getzola.org/) and a hand-written stylesheet
(no Node, no CSS build step). Hosted on **Cloudflare Pages**, which builds and
deploys automatically on every push to `master`.

## Repository layout

```
.
├── config.toml            # site config + [extra] contact data (single source of truth)
├── content/_index.md      # homepage front matter (template = index.html)
├── templates/
│   ├── base.html          # <head>, meta/OG, JSON-LD (Organization), header, footer
│   ├── index.html         # all homepage sections + FAQPage JSON-LD
│   └── robots.txt         # robots.txt / sitemap are generated by Zola
├── static/
│   ├── css/site.css       # the whole stylesheet (no inline styles anywhere)
│   ├── fonts/             # self-hosted woff2 (+ OFL licence texts)
│   ├── img/               # logo, favicons, og-image.jpg, sorting-scan.svg, bottle svgs
│   ├── _headers           # Cloudflare Pages security + cache headers
│   ├── llms.txt
│   └── apple-touch-icon.png
├── brand/                 # source/exports for brand assets (not deployed)
└── Makefile               # build / serve / deploy
```

### Contact data lives in one place

Phone, email, addresses, CVR and the meta/OG texts are defined once in
`config.toml` under `[extra]` and referenced from the templates. Change the
phone number there, not in the markup.

## Local development

```sh
make serve     # http://127.0.0.1:1111 with live reload
make build     # one-off build into public/
```

Needs only [`zola`](https://www.getzola.org/documentation/getting-started/installation/) (v0.22+).

## Deploy

**Push to `master` → Cloudflare Pages builds and publishes.** There is no
manual step.

| Cloudflare Pages setting | Value |
|---|---|
| Build command | `zola build` |
| Build output directory | `public` |
| Production branch | `master` |
| `ZOLA_VERSION` (build variable) | `0.22.1` |

`make deploy` just builds locally and reminds you to commit and push.

### Caching

`css/site.css` and `img/sorting-scan.svg` are referenced with
`?v={{ config.extra.asset_version }}` and cached for a long time. **Bump
`asset_version` in `config.toml` whenever you change either file.**

### CSP

`static/_headers` sets a strict CSP (`script-src 'self'; style-src 'self'`).
Do not add inline `<script>`, `<style>` or `style=""` attributes — put styles
in `static/css/site.css`.

## Brand and imagery

- **Logo:** `static/img/logo.svg` (traced vector). Lockups with wordmark are in
  `brand/` (SVG + 3200 px PNG).
- **Scan animation:** `static/img/sorting-scan.svg` is a self-contained
  animated SVG (CSS animations, no JavaScript, respects reduced motion).
  `brand/sorting-scan-poster.png` is a still of it.
- **Open Graph / Twitter image:** `static/img/og-image.jpg` (1200×630). Its
  source is `brand/og-image.svg` (text outlined). Re-render with:
  ```sh
  rsvg-convert -w 1200 -h 630 brand/og-image.svg -o /tmp/og.png
  magick /tmp/og.png -quality 90 -strip static/img/og-image.jpg
  ```
  After changing it, bump `asset_version` and ask Facebook/LinkedIn to
  re-scrape (their debuggers) so previews refresh.
- **Favicons:** `static/img/favicon*.png`, `static/apple-touch-icon.png`.

## Out-of-repo configuration

| Concern | Lives in |
|---|---|
| `ZOLA_VERSION` build pin | Cloudflare Pages → Settings → Variables and secrets |
| Custom domain + apex → www redirect | Cloudflare Pages → Custom domains |
| Email Address Obfuscation | Cloudflare → Scrape Shield (keep **off**: it rewrites `mailto:` links) |
| SPF, DKIM, DMARC, CAA | DNS for `kemisortering.dk` |
